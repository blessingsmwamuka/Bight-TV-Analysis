
Bright TV Analysis

 📖 Project Overview

This project analyzes user profiles and viewer transaction data from **BrightTV** to generate actionable insights that support business growth.

The analysis is designed to help the Customer Value Management (CVM) team make data-driven decisions that improve customer acquisition, retention, engagement, and overall subscription performance.


 🎯 Project Objective

The primary objective of this project is to:

- Analyze customer subscription and viewing behavior.
- Identify factors that influence customer retention and churn.
- Evaluate user engagement across different customer segments.
- Provide data-driven recommendations to grow the subscription base and improve customer lifetime value.


❓ Business Questions

- Which customer segments generate the highest revenue?
- What factors contribute to customer retention and churn?
- Which subscription plans perform the best?
- How engaged are customers based on their viewing behavior?
- What trends can be identified in subscription and viewing activity?
- What strategies can increase customer acquisition and retention?

 📋 Project Tasks

 Task 1: Project Planning

- Defined the business objectives and key performance indicators (KPIs).
- Planned the data analysis workflow.
- Designed the project architecture using Miro.


Task 2: Data Preparation

- Imported customer and transaction datasets.
- Cleaned and transformed the data.
- Prepared the data for analysis by handling missing values and inconsistencies.


 Task 3: Data Analysis

- Analyzed customer subscription trends.
- Examined viewer engagement and usage patterns.
- Evaluated customer segmentation and revenue performance.
- Identified factors affecting customer retention and churn.


 Task 4: Dashboard Development

- Developed interactive Power BI dashboards.
- Visualized KPIs using charts and graphs.
- Presented insights and recommendations through business reports.


 📈 Key Insights

The analysis identified:

- High-value customer segments.
- Customer engagement and viewing trends.
- Subscription performance across different plans.
- Factors influencing customer retention and churn.
- Opportunities to improve customer acquisition, engagement, and long-term profitability.
